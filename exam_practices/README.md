## How to use this section

Don't just memorize answers — for each question, capture **why** the right
answer is right *and* why the distractors are wrong. That's what the exam tests.

### Suggested question template

```markdown
### Q<n>. <topic>

**Question:** <paste the scenario>

- [ ] A. ...
- [ ] B. ...
- [x] C. ...   ← correct
- [ ] D. ...

**Why C:** <reasoning>
**Why not A/B/D:** <the trap in each distractor>
**Service docs:** <link>
```

> 💡 Pair this with the [cheatsheets](../cheatsheets) (quick recall) and the
> [mind maps](../mind_maps) (the big picture).
